# jeane.dev

**Hello world! I am a self taught dev with more than 10 years of building things under my belt. My personal site, dev blog, and projects, live at [jeane.dev](https://jeane.dev)**

Built with [Next.js](https://nextjs.org), React, TypeScript, and Tailwind CSS. Blog posts are Markdown files in `posts/`, rendered at build time with remark.

## Getting Started

Requires Node.js and [pnpm](https://pnpm.io).

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command       | Description              |
| ------------- | ------------------------ |
| `pnpm dev`    | Start the dev server     |
| `pnpm build`  | Create a production build |
| `pnpm start`  | Serve the production build |
| `pnpm test`   | Run tests with Vitest    |
| `pnpm lint`   | Lint with ESLint         |
